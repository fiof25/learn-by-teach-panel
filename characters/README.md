# Character Trait Quick Reference

## The 9 Traits
1. Intelligence (1-5): Processing speed
2. Feedback Frequency (1-5): How often seeks validation
3. Energy (1-5): Response length (1=1 sentence, 3=2-3 sentences, 5=4-6 sentences)
4. Effort Tolerance (1-5): Willingness to work
5. Compliance (1-5): Cooperative vs oppositional
6. Attention Span (1-5): Focus vs distraction
7. Mistakes (1-5): Error frequency
8. Politeness (1-5): Rude vs nice
9. Cognitive Style: Concrete/Flexible/Abstract

## Character Profiles

**Jamie 🦫**: 3-4-5-3-4-1-2-5-Concrete
- 4-6 sentence enthusiastic responses with tangents
- Super friendly but constantly distracted

**Thomas 🦆**: 5-2-3-5-3-5-1-3-Abstract  
- 2-3 sentence precise responses
- Demands formal rigor

**Sam 🦥**: 3-2-1-1-3-2-3-2-Flexible
- Single sentence lazy responses
- "Just tell me"

**Alex 🐊**: 4-5-4-4-1-4-2-1-Abstract
- 3-5 sentence aggressive debates
- Very rude

**Avery 🐧**: 1-5-3-3-5-3-5-5-Concrete
- 2-3 sentence confused responses
- Many mistakes, very polite
